# サブスク管理アプリ

サブスクの一覧・毎月/年間の合計金額・おすすめ解約日の計算・カレンダー表示・毎月の支出推移グラフをまとめて管理する、スマホ向けのシンプルなWebアプリです。

## 使い方

`index.html` を開くだけで動きます。ビルド不要、外部ライブラリ不要の単一HTMLファイルです。

- **ローカルで試す**: このファイルをブラウザで直接開くか、`npx serve` などの簡易サーバーで配信してください。
- **公開する**: このリポジトリをGitHub Pagesで公開すれば、スマホのブラウザからいつでもアクセスできます(Settings → Pages → Source を `main` ブランチの `/`(root)に設定)。

## データの保存場所

サブスクの情報・毎月の記録は、開いたブラウザの `localStorage` に保存されます。**どこにも送信されず、他端末とは同期しません。** ブラウザのサイトデータを消すと、この情報も消えるのでご注意ください。

## 制限事項

このアプリには「ロゴ画像をアップロードする」機能がありますが、これは元々 [Claude Artifacts](https://claude.ai) というAnthropicのプラットフォーム上の拡張機能(`assets` capability)を使って実装されていました。**GitHub Pagesなど、Claude Artifacts以外の場所で開いた場合、この画像アップロード機能は動きません**(自動で非表示になり、代わりに名前の頭文字による色付きバッジが表示されます)。それ以外の機能(サブスクの追加・編集・削除、カレンダー、支出推移グラフ)はすべて通常通り動作します。

もし画像アップロードを復活させたい場合は、ブラウザ内(localStorageやIndexedDB)に直接画像を保存する方式に作り替える必要があります。

## 構成

すべて `index.html` 1ファイルの中に、HTML・CSS・JavaScriptがまとまっています。主なセクション:

- 日付計算・請求日/解約目安日のロジック
- ホーム画面(一覧・合計金額)
- 追加/編集画面
- 詳細画面
- カレンダー画面
- 支出推移グラフ画面
